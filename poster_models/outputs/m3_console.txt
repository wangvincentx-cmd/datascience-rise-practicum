=== JOINT TEST: do claim features add anything over the economy? ===
  H0: every claim-feature partial effect is zero
  chi2(16) = 1633.08   p = 0   (cluster-robust, 22 blocks)
  -> Reject. Wording carries information about accuracy that the economy
     does not. This is the properly-sized version of a positive AUC delta.

  Which features carry it (2 individually significant):
    c_direction_no_change      -0.3389  95% CI [-0.4388, -0.2389]
    c_topic_general_business   +0.1580  95% CI [+0.0316, +0.2844]
  Check before quoting: a rejection driven by c_direction_* is largely the
  base-rate asymmetry -- 'improve' hits ~60% because expansions are common --
  not evidence that WORDING matters. The stylistic features (hedged, quoted,
  named, has_number, len) are the ones that speak to how a forecast was written.

=== narrower test: STYLE features only (c_hedged, c_quoted, c_named, c_has_number, c_len) ===
  chi2(5) = 2.87   p = 0.7201
  This drops direction and topic -- which encode WHAT was predicted -- and
  keeps only HOW it was written. This is the poster's actual question.

  The two tests together are the headline: the full test rejects, the style
  test does not. What a forecast PREDICTED carries real information about
  whether it came true; HOW it was written carries none that survives the
  economy and honest clustering.
  -> poster_models/outputs/m3_dml_summary.csv
